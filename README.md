# WeGoWhere - ค้นหากิจกรรม เชื่อมต่อเพื่อนใหม่

WeGoWhere เป็นแพลตฟอร์มที่ช่วยให้คุณค้นหาและเข้าร่วมกิจกรรมที่น่าสนใจ พบปะเพื่อนใหม่ที่มีความสนใจเหมือนกัน และสร้างประสบการณ์ดีๆ ร่วมกัน

## คุณสมบัติเด่น

- 🎯 **ค้นหากิจกรรม** - ค้นหากิจกรรมที่ตรงใจและเหมาะกับคุณ
- 👥 **เชื่อมต่อเพื่อน** - พบปะเพื่อนใหม่ที่มีความสนใจเหมือนกัน  
- 🎉 **สร้างประสบการณ์** - สร้างความทรงจำดีๆ ร่วมกับเพื่อนใหม่
- 💬 **แชทสด** - คุยกับเพื่อนๆ ในแอปพลิเคชัน
- 📱 **ใช้งานง่าย** - ออกแบบมาให้ใช้งานง่ายบนทุกอุปกรณ์

## วิธีการใช้งาน

1. **สมัครสมาชิก** - สร้างบัญชีผู้ใช้ของคุณ
2. **ค้นหากิจกรรม** - เลือกกิจกรรมที่สนใจ
3. **เข้าร่วม** - เข้าร่วมกิจกรรมและพบปะเพื่อนใหม่
4. **สร้างความสัมพันธ์** - แชทและสื่อสารกับสมาชิกคนอื่นๆ

## เทคโนโลยีที่ใช้

- **Frontend**: Next.js 16, React 19, TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Form Handling**: React Hook Form
- **Real-time Chat**: Socket.IO
