# Debtly - จัดการหนี้แสนสนุก

Debtly เป็นแอปพลิเคชันจัดการหนี้สินที่ทำให้การจัดการเงินและหนี้เป็นเรื่องง่ายและสนุก ติดตามรายรับรายจ่าย วางแผนการเงิน และจัดการหนี้อย่างเป็นระบบ

## คุณสมบัติเด่น

- 💰 **จัดการหนี้** - ติดตามและจัดการหนี้สินได้อย่างเป็นระบบ
- � **วิเคราะห์เงิน** - รายงานและสถิติการเงินที่เข้าใจง่าย  
- � **วางแผนการเงิน** - ตั้งเป้าหมายและแผนการชำระหนี้
- 📱 **ใช้งานง่าย** - ออกแบบมาให้ใช้งานง่ายบนทุกอุปกรณ์
- 🔒 **ปลอดภัย** - ข้อมูลการเงินของคุณปลอดภัยและเป็นความลับ

## วิธีการใช้งาน

1. **สมัครสมาชิก** - สร้างบัญชีผู้ใช้ของคุณ
2. **เพิ่มหนี้** - บันทึกรายการหนี้สินต่างๆ
3. **ติดตามการจ่าย** - ตรวจสอบสถานะการชำระหนี้
4. **วิเคราะห์การเงิน** - ดูรายงานและวางแผนการเงิน

## เทคโนโลยีที่ใช้

- **Frontend**: Next.js 16, React 19, TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Form Handling**: React Hook Form
- **Charts**: Recharts
